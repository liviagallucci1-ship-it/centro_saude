# Sistema de Gestão de um Centro de Saúde

## Sobre o Projeto em Contexto Académico

**Curso:** Técnico Superior de Tecnologia e Inovação Informática  
**Unidade Curricular:** Fundamentos de Algoritmos e Estruturas de Dados (FAED)  
**Projeto:** Sistema de Gestão de um Centro de Saúde

Este projeto foi desenvolvido em grupo e consiste na criação de um sistema de gestão de um centro de saúde, utilizando a linguagem de programação C, no âmbito da Unidade Curricular de Fundamentos de Algoritmos e Estruturas de Dados (FAED).

### Objetivo

Com este projeto, procurámos aplicar de forma prática os conhecimentos adquiridos ao longo da unidade curricular, recorrendo a diferentes conceitos de programação, nomeadamente variáveis, constantes, arrays, estruturas condicionais e estruturas de repetição. A utilização destes conceitos permitiu-nos desenvolver um programa com várias funcionalidades, orientado para a resolução do problema proposto.

---

## Apresentação do Projeto

O projeto consiste num programa de gestão de um centro de saúde, que possui uma interface textual com capacidade para apresentar ao utilizador diversas opções de ações através do menu principal.

### Funcionalidades

O sistema permite realizar as seguintes funcionalidades:

**1 - Registar Utente:** permite introduzir os dados de um novo utente, incluindo o nome, a idade e o número de telefone. Cada utente recebe ainda automaticamente um ID próprio.

**2 - Marcar Consulta:** permite selecionar um utente já registado e marcar uma consulta médica através do seu ID. Num segundo menu, é possível escolher a especialidade médica pretendida, entre Medicina Geral, Pediatria ou Enfermagem.

**3 - Cancelar Consulta:** permite cancelar uma consulta através do respetivo ID.

**4 - Mostrar Utentes:** apresenta uma listagem dos utentes registados, com os respetivos dados.

**5 - Mostrar Totais:** apresenta o número total de utentes, as consultas registadas, consultas em vigor e consultas canceladas.

**0 - Sair:** permite terminar a execução do programa.

### Limites do Sistema

Inicialmente, também foi definido um limite máximo para os registos, estabelecendo-se uma capacidade máxima de 100 utentes e 300 consultas. A escolha foi tomada com o objetivo de definir limites para a utilização dos arrays e facilitar a organização do código.
